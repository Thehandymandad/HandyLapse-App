# Brand kit — stile zane

| Cosa | Valore |
|---|---|
| Fondo delle scene | quasi nero con una punta di verde `#050805`, vignetta radiale d'accento al centro che respira |
| Accento | lime acceso `#CCFF00` (varianti viste: `#39FF14`, `#00FF66`), sempre con bagliore |
| Card / pillole | vetro scuro verdastro `rgba(10,16,9,0.86)`, bordo d'accento al 20%, angoli arrotondati (pillole a 999) |
| Parola principale | Inter 900, bianco, interlinea stretta, tracking −0.045em |
| Parola d'accento | Instrument Serif corsivo, colore d'accento con bagliore |
| Etichette tecniche | mono (header di capitolo, "B-ROLL 02 · EYES") |
| Sottotitoli | parola per parola, bianco pesante; la parola chiave in serif corsivo d'accento |
| Struttura | barra del capitolo fissa in alto (numero mono + titolo + tacche); scene grafiche a schermo intero alternate al parlato |
